# Эхо 2174 — UI SPEC контрольного прототипа

Базовая виртуальная сетка: **1920×1080, landscape 16:9, mobile-first**.

## Зафиксированные размеры

Эти размеры считаются минимальным ориентиром для телефона. Мельче делать только после отдельного теста на реальном устройстве.

- Верхняя кнопка `Журнал / Карта / Меню`: **170×124 px**.
- Иконка внутри верхней кнопки: ориентир **54 px**.
- Подпись верхней кнопки: ориентир **26 px**.
- Кнопка `Осмотреть`: **205×205 px**.
- Иконка лупы: ориентир **82 px**.
- Подпись `Осмотреть`: ориентир **27 px**.
- Нижняя шторка реплики: минимальная высота **190 px**.
- Аватар говорящего: **118×118 px**.
- Основной текст реплики: ориентир **30 px**.

## Слой UI

UI не рисуется внутри фоновой сцены. Используются раздельные слои: сцена, UI и при необходимости служебный debug-слой.

## Верхняя шторка

Светло-голубой / бирюзовый AR-язык. Шторка уезжает вправо, оставляет понятный маркер и автоматически скрывается в режиме `Осмотреть`.

## Нижняя шторка

Содержит аватар говорящего, может опускаться вниз. Новое сообщение обязательно автоматически раскрывает её. Тап по пустой сцене сворачивает шторки, если игрок не находится в активном выборе области.

## Режим «Осмотреть»

На сцене нет отдельных значков-луп над уликами.

`Осмотреть → тап по любой области → auto-crop → preview → Сохранить наблюдение`

Наблюдение и анализ Аркадия — разные действия.
