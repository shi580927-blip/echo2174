# Эхо 2174 — контрольный прототип Этапа 3

Публичный репозиторий для мобильной проверки одной контрольной сцены. Это не полноценная разработка всей игры.

## Что проверяем

`Осмотреть → выбрать область → crop/preview → Сохранить наблюдение → Журнал → Отправить Аркадию → Факт/контекст/шум → Версия → Проверяемое следствие → Проверка`

## База интерфейса

- виртуальная сетка 1920×1080;
- mobile-first landscape 16:9;
- UI не вшивается в арт сцены;
- верхняя AR-шторка Журнал / Карта / Меню уезжает вправо;
- нижняя шторка реплик содержит аватар говорящего;
- новое сообщение автоматически раскрывает реплику;
- крупная кнопка «Осмотреть»;
- никаких отдельных значков-луп над уликами;
- наблюдение и анализ Аркадия — разные действия.

## Контрольная сцена

Для первого мобильного теста используем Фас A: карта, скамья и окружающая зона. Финальный чистый арт ещё не утверждён. Временный тестовый арт подключается отдельно.
